# 🗄️ Retail Inventory Management Database

A relational database project designed to manage inventory, suppliers, customers, and orders for a small retail company.

## 📌 About the Project

The project involved designing and implementing a relational database system for a retail company.

The database was designed to manage:

- Products
- Suppliers
- Customers
- Orders
- Order Details

Primary and foreign keys were used to establish relationships between the tables and maintain data consistency.

## 🧰 Technologies Used

- SQL
- Relational Database
- SQL Queries
